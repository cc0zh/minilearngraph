# v0.2.0 — 本机学习目标与图谱

## 新增能力

- Web 引导学习目标澄清，支持模型动态问题、选项、自定义、跳过和透明假设审阅；确认目标与发布图谱均由用户明确操作。
- 候选图谱支持节点与关系编辑；正式图谱修订需确认与说明。联合 DAG 校验、revision 并发保护和历史快照避免非法结构与旧修改覆盖。
- FastAPI 与 SQLite 保存目标、图谱、失败状态和内容版本，刷新与重启后可继续查询、显式重试。
- CLI 新增可选 `--trace`，显示模型与工具步骤、耗时和停止原因，不记录用户内容或密钥；原有对话、工具、reset/exit 保持可用。
- 源码包保留完整项目文档、Web 源码与锁文件，并检查本地文档链接；不包含真实数据库、环境配置或依赖缓存。

## 安装与使用

下载并解压 `repo-metadata.tgz`，需要 Python 3.11+、uv 和 Node.js 22.12+。

```powershell
uv sync --locked
Copy-Item .env.example .env
uv run --locked python -m mini_learngraph.api
```

API 默认 `http://127.0.0.1:8000`。另开终端启动 Web：

```powershell
cd web
npm.cmd ci
npm.cmd run dev
```

Web 默认 `http://127.0.0.1:5173`；macOS/Linux 使用 `npm` 和 `cp`。不要覆盖已有 `.env`。生成澄清和图谱需要在本地配置兼容模型；无模型配置仍可启动 API、查询已有资产和运行离线测试。

## 兼容与边界

- 仅供本机个人使用：回环地址、固定 `local-user`，不支持 LAN、公网或多人认证；本次发布源码，不部署服务，也不发布 npm/PyPI 包。
- B1 软件契约已通过固定 Provider 验收；真实 B1 模型效果尚未验证。B2 节点教学、B3 作答证据、B4 下一步建议尚未实现；包内 B2 文档是待复核设计，不是已交付能力。
- 当前数据库为 schema v1；未知版本不自动升级。已有数据需关闭服务并一致备份，不删除数据库重建。
- 直接调用 `ToolRegistry.execute` 的代码使用 `ToolResult.text/is_error`，而非将返回值作为字符串。
- 已知限制：Starlette TestClient 弃用提示；npm 镜像 audit 不可用的历史记录不代表依赖安全审计通过。
